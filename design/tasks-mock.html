Priority, only if you set it

Priority stays optional. A task without one looks like every task above. Set it with !1, !2 or !3 while typing, or from the right-click menu. The three colours are the same on every skin, and each comes with a ! mark so it doesn't rely on colour alone. Pick the style you like; the window above uses the one you select.

With any style: tasks sort by priority inside each section, then by time. A P1 task that's still open at its reminder time gets one follow-up nudge an hour later.

How it behaves

The rules

Done tasks stay crossed out until the day ends, then drop into a "Done" history (Stats tab gets a simple count).
Unfinished tasks from earlier days move into today under "From earlier", in red, with how many days late.
Inbox holds tasks with no date. Drag one onto Today, or give it a day in the editor.
Upcoming lists the next 7 days, grouped by day.
Labels are free text. Each gets a colour from a fixed set that works on all six skins; you can change it in Settings.
Hold-to-check is for habits. Tasks tick with one click, with undo in the toast.
Reset in Settings asks whether to clear habits, tasks or both.
Export/Import JSON and CSV include tasks.
Left out on purpose
Repeating tasks. If it repeats, it's a habit.
Subtasks, projects and due-date-vs-start-date.
